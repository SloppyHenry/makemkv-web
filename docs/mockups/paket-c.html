Mehrere Installationen von MakeMKV-Web bilden einen Verbund: gemeinsame Aufträge, Übergabe von Konvertierungen, Fernsteuerung der Laufwerke.

So sehen ihn die anderen Rechner. Standard: der Hostname.

Eigenständig: keine anderen Rechner, keine Suche, keine Verbund-Knöpfe.

Nicht gefunden? Ein Rechner taucht nur auf, wenn bei ihm unter Einstellungen › Rechner „Im Netz auffindbar“ eingeschaltet ist. Rechner mit älterer Version (z. B. secondtux) lassen sich nur per Adresse hinzufügen. Läuft dieser Rechner in Docker, durchsucht er das Netz, über das du die Seite aufgerufen hast (192.168.178.0/24); ein anderes Netz kannst du unter „Netz für die Suche“ eintragen.
